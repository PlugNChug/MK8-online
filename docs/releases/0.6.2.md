### What's fixed

- **Linux: the launcher recognizes a finished build again.** In 0.6.0 and 0.6.1 two build capabilities were read from a Windows DLL, so on Linux the build always looked outdated: additional content and rooms stayed locked even though solo play worked ([#128](https://github.com/Vnnc1/MK8-online/issues/128)). Run **Update the build** once after updating.
- **Linux: Steam Controller on Wayland.** When Steam starts MK8-online in a Wayland session, the game now runs through XWayland, so Steam follows the game window and the controller leaves desktop mode ([#131](https://github.com/Vnnc1/MK8-online/issues/131)). Setting `SDL_VIDEODRIVER` yourself still takes precedence.
- **No more closing while a race loads with "completed occlusion queries unavailable".** When the graphics driver did not return the results of these visibility checks, the game stopped on purpose. It now treats them as visible and keeps running ([#127](https://github.com/Vnnc1/MK8-online/issues/127)).

Everything from [0.6.0](https://github.com/Vnnc1/MK8-online/releases/tag/v0.6.0) and [0.6.1](https://github.com/Vnnc1/MK8-online/releases/tag/v0.6.1) is included.

Bring your own game files, update 4.0.1 and console keys. Each package has a companion SHA-256. Include your GPU, driver, mode, track and a **Support → Create report** ZIP when reporting an issue. ### O que foi corrigido

- **Linux: o launcher volta a reconhecer a build concluída.** Na 0.6.0 e na 0.6.1, duas capacidades da build eram lidas de uma DLL do Windows, e no Linux a build sempre parecia desatualizada: o conteúdo adicional e as salas ficavam bloqueados, embora o jogo solo funcionasse ([#128](https://github.com/Vnnc1/MK8-online/issues/128)). Rode **Atualizar a build** uma vez depois de atualizar.
- **Linux: Steam Controller no Wayland.** Quando a Steam abre o MK8-online numa sessão Wayland, o jogo passa a rodar pelo XWayland. Assim a Steam acompanha a janela do jogo e o controle sai do modo desktop ([#131](https://github.com/Vnnc1/MK8-online/issues/131)). Se você definir `SDL_VIDEODRIVER`, a sua escolha continua valendo.
- **O jogo não fecha mais ao carregar uma corrida com "completed occlusion queries unavailable".** Quando o driver de vídeo não devolvia os resultados dessas verificações de visibilidade, o jogo parava de propósito. Agora elas contam como visíveis e o jogo continua ([#127](https://github.com/Vnnc1/MK8-online/issues/127)).

Tudo da [0.6.0](https://github.com/Vnnc1/MK8-online/releases/tag/v0.6.0) e da [0.6.1](https://github.com/Vnnc1/MK8-online/releases/tag/v0.6.1) continua incluído.

Use seus próprios arquivos do jogo, atualização 4.0.1 e chaves do console. Cada pacote acompanha um SHA-256.
