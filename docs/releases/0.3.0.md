# MK8-online 0.3.0 — CTGP Deluxe on 4.0.1 & Launcher Overhaul (Experimental)

<details open>
<summary><strong>English</strong></summary>

## A larger update, still a public test

**0.3.0 brings CTGP Deluxe course support to MK8 Deluxe 4.0.1, a redesigned launcher, optional DLC management and the accepted fix-chore contributions. It is not 100% complete or stable: expect bugs, visual defects and uneven performance. Steam multiplayer remains experimental.**

### Highlights

- **CTGP Deluxe on 4.0.1.** CTGP Deluxe 1.1.1 originally targets MK8 3.0.3 (32-bit). This project's adaptation imports its course resources into the 4.0.1 AArch64 recompilation, including **64 courses in 16 additional cups**, with names, cup icons, course pictures and music. Original courses remain available in the additional-cup layout. Base/DLC replacement layouts are also available. This does not run CTGP's original plugin or reproduce every CTGP feature.
- **A redesigned launcher.** Dark/orange design, horizontal installation stages (Tools → Game files → Build → Additional content), reuse of existing tools and clearer readiness/error states. Settings are organized into modules, with game language accessible from Play, a guided Mii creation flow, clearer Steam friends/rooms and improved support reports.
- **Optional Booster Course Pass.** Select your own DLC package during preparation or import it later, then enable/disable it in Settings. Reinstallation and missing-file checks are supported; Steam participants must match DLC and CTGP states. No DLC or game files are included.
- **Mii improvements.** The creator no longer blocks the entire launcher while loading its large parts library; active Mii selection and glasses texture conversion are corrected. The verified library download retains its Internet Archive attribution and local-file fallback. Regenerate existing derived Mii resources to apply conversion changes.
- **Runtime and startup improvements.** Vulkan dependency checks, shared-memory handling for integrated GPUs, safer texture lifetime handling, replay thumbnail readback, a local How to Play guide, private console-font import/system fallback, particle shader translation and an audio voice-start ramp. These address specific failures rather than every crash or rendering defect.
- **Performance and controls.** High-resolution Windows shader waits and a budget for the two-player split-screen scene reduce measured stalls. Controller setup no longer reports success when too few players are present. CRLF settings parsing is fixed, including the existing experimental 120 FPS frame-generation option: presentation can reach about 120 FPS in tested sections, while simulation stays at 60 Hz. It remains off by default.
- **Steam integration.** Improved DLL discovery/versioned interfaces, searchable friends, handling of large LAN packets and automatic/manual room navigation. Includes accepted contributions from PRs **#9, #12, #18, #19, #25, #27–31 and #33**, plus the CTGP integration and subsequent launcher/performance work.

### Update and prepare

1. Install the attached **MK8-online-0.3.0-setup.exe**, or use **Support → Update now**. Keep your existing data folder; saves and profiles are preserved.
2. **Run Build the game again** to apply the new runtime and CTGP integration. Updating only the launcher does not update an already prepared game.
3. Use your own base game, **4.0.1 update**, console keys and optional DLC. Import your own extracted CTGP package through **Install → Additional content**, then select/enable its layout in Settings. CTGP uses separate saves initialized from a copy of yours.
4. For Steam tests, update both PCs and use matching game/DLC/CTGP configurations. Steam must be signed in; a compatible local `steam_api64.dll` remains required. No Valve DLL is distributed.

### Known limitations — please read

- **CTGP is not fully compatible or qualified.** Track-specific graphical defects, shader stutters, crashes and performance drops can remain. Its original custom menus/random button are unavailable; staff ghosts and record slots have inherited limitations. Additional CTGP cups are not qualified online; network sessions use the game's cup flow.
- **Steam reconnection has a known bug:** a guest returning to the same host room can remain pending. Creating a new host room is the current workaround to try. Automated LAN entry can stop before the in-game lobby; manual navigation is available. A complete race between two PCs is still unqualified.
- Vulkan startup can still fail on some PCs even after the dependency precheck passes. Memory-allocation crashes on Intel/AMD integrated GPUs and reported NVIDIA rendering defects are not confirmed fixed.
- First-use shader compilation can still pause the game. Improvements measured on the test PC do not guarantee 60 FPS on every track or system. Frame generation can distort moving edges and does not improve the simulation rate or solve GPU bottlenecks.
- Some controllers require disabling **Steam Input for Spacewar**, then restarting both launcher and game while keeping Steam open. Three/four-player local play remains unqualified.
- `gameplay_verified` and `multiplayer_verified` remain **false**. This is a **Windows x64 experimental pre-release**, not a Linux/Android release.

Please report the track/mode, steps, CPU/GPU, driver and version **0.3.0**, with the ZIP from **Support → Generate report**. For multiplayer, attach reports from both PCs. Review attachments and never upload game files, keys or saves.

## Uma atualização maior, ainda para testes

**A 0.3.0 traz pistas do CTGP Deluxe para o MK8 Deluxe 4.0.1, launcher redesenhado, gerenciamento de DLC opcional e as contribuições aceitas na fix-chore. Não está 100% completa ou estável: ainda haverá bugs, defeitos visuais e variações de desempenho. O multiplayer Steam continua experimental.**

### Destaques

- **CTGP Deluxe no 4.0.1.** O CTGP Deluxe 1.1.1 foi feito para o MK8 3.0.3 (32 bits). Nossa adaptação importa os recursos das pistas na recompilação AArch64 do 4.0.1, incluindo **64 pistas em 16 copas adicionais**, com nomes, ícones, imagens e músicas. O layout de copas adicionais preserva as pistas originais; também existem layouts que substituem copas do jogo base/DLC. Isso não executa o plugin original nem reproduz todos os recursos do CTGP.
- **Launcher redesenhado.** Visual escuro/laranja, instalação horizontal (Ferramentas → Arquivos do jogo → Build → Conteúdo adicional), reutilização das ferramentas e estados de prontidão/erro mais claros. Configurações em módulos, idioma do jogo acessível em Jogar, criação guiada de Mii, amigos/salas Steam mais organizados e relatórios de suporte melhorados.
- **Booster Course Pass opcional.** Selecione seu pacote DLC na preparação ou importe depois e ative/desative em Configurações. Há reinstalação e verificação de arquivos ausentes; participantes Steam precisam usar o mesmo estado de DLC e CTGP. Nenhum DLC ou arquivo do jogo é distribuído.
- **Melhorias Mii.** O carregamento da biblioteca de peças não bloqueia mais todo o launcher; correções na seleção do Mii ativo e nas texturas dos óculos. O download verificado mantém a identificação do Internet Archive e a opção de arquivo local. Regenere recursos Mii derivados existentes para aplicar as mudanças do conversor.
- **Runtime e inicialização.** Verificação de dependências Vulkan, tratamento de memória compartilhada em GPUs integradas, referências de texturas mais seguras, leitura das miniaturas MKTV, guia local How to Play, importação privada de fontes/fallback do sistema, tradução de shaders de partículas e rampa de início das vozes de áudio. São correções específicas, não garantia de eliminação de todos os crashes ou defeitos gráficos.
- **Desempenho e controles.** Esperas de shaders com temporizador Windows de alta resolução e orçamento para a cena dividida em dois jogadores reduzem engasgos medidos. A seleção de controles não retorna sucesso com jogadores insuficientes. Corrigida a leitura CRLF de configurações, incluindo a geração experimental de quadros a 120 FPS já existente: a apresentação pode chegar perto de 120 FPS nos trechos testados, mantendo a simulação em 60 Hz. Continua desligada por padrão.
- **Steam.** Melhorias na descoberta de DLLs/interfaces, pesquisa de amigos, transporte de pacotes LAN grandes e navegação automática/manual. Inclui contribuições aceitas das PRs **#9, #12, #18, #19, #25, #27–31 e #33**, integração CTGP e trabalhos posteriores de launcher/desempenho.

### Atualizar e preparar

1. Instale **MK8-online-0.3.0-setup.exe**, anexado abaixo, ou use **Suporte → Atualizar agora**. Mantenha sua pasta de dados; saves e perfis são preservados.
2. **Execute novamente o Build do jogo** para aplicar o runtime e a integração CTGP. Atualizar somente o launcher não atualiza o jogo já preparado.
3. Use seu jogo base, **atualização 4.0.1**, chaves do console e DLC opcional. Importe sua cópia extraída do CTGP em **Instalar → Conteúdo adicional** e escolha/ative o layout em Configurações. O CTGP usa saves separados, inicializados com uma cópia dos seus.
4. Para testar Steam, atualize os dois PCs e mantenha jogo/DLC/CTGP compatíveis. Steam conectada e uma `steam_api64.dll` local compatível continuam necessárias. Nenhuma DLL Valve é distribuída.

### Limitações conhecidas — leia antes de testar

- **CTGP ainda não está totalmente compatível ou qualificado.** Podem persistir defeitos gráficos por pista, engasgos de shaders, crashes e quedas de desempenho. Menus próprios/botão aleatório não estão disponíveis; fantasmas e posições de recordes têm limitações herdadas. Copas CTGP adicionais não estão qualificadas online; sessões de rede usam o fluxo de copas do jogo.
- **Existe um bug de reconexão Steam:** o convidado pode ficar pendente ao voltar à mesma sala. Criar uma nova sala no anfitrião é o contorno atual a tentar. A entrada LAN automática pode parar antes do lobby do jogo; há navegação manual. Corrida completa entre dois PCs continua sem qualificação.
- A inicialização Vulkan ainda pode falhar em alguns PCs após a verificação de dependências. Crashes de alocação em GPUs Intel/AMD integradas e defeitos gráficos relatados em NVIDIA não estão confirmados como resolvidos.
- Shaders novos ainda podem causar pausas. As melhorias medidas no PC de testes não garantem 60 FPS em toda pista/máquina. Geração de quadros pode deformar bordas em movimento, não aumenta a simulação nem resolve gargalos de GPU.
- Alguns controles precisam desativar **Entrada Steam para Spacewar** e reiniciar launcher/jogo, mantendo a Steam aberta. Multiplayer local com três/quatro jogadores continua sem qualificação.
- `gameplay_verified` e `multiplayer_verified` continuam **false**. É uma **pré-release experimental para Windows x64**, não uma versão Linux/Android.

Relate pista/modo, passos, CPU/GPU, driver e versão **0.3.0**, anexando o ZIP de **Suporte → Gerar relatório**. Para multiplayer, envie os relatórios dos dois PCs. Revise os anexos e nunca publique arquivos do jogo, chaves ou saves.
